Infographic Description (Task 1)
-
The infographic, titled "Navigating the Digital World: A Student's Guide," serves as the visual resource required for Task 1. It covers three essential topics mandated 
by the project brief:What is Digital Literacy?: It defines the concept through skills like evaluating information, critical thinking, and ethical digital creation.
Useful Digital Tools: It categorizes student resources into document tools, communication, research databases, cloud storage, productivity apps, and graphic design 
software.Safe Internet Practices: It provides a checklist for security, including strong passwords, recognizing phishing, using HTTPS, and practicing social media
privacy.
